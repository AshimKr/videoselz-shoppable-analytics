# Videoselz Shoppable Video Analytics

A full-stack shoppable video analytics dashboard built as part of the Videoselz Full Stack Developer technical evaluation.

## Tech Stack

- React
- Vite
- Node.js
- Express
- Prisma
- SQLite

## Project Structure

- `client` - React frontend
- `server` - Express REST API
- `server/prisma` - Database schema and migrations
